# Участие в разработке

[English version](CONTRIBUTING.md)

Мы принимаем изменения на условиях лицензии репозитория с обязательной атрибуцией.

1. Создайте issue с описанием workflow или ошибки.
2. Сохраняйте архитектуру skills-only и обязательное явное подтверждение перед любой записью.
3. Не добавляйте реальные данные Mattermost или учётные данные в примеры и тесты.
4. Обновляйте соответствующую документацию на русском и английском.
5. Запустите `python3 -m unittest discover -s tests -v` и оба валидатора из README.
6. Отправьте сфокусированный pull request и сохраняйте обязательную атрибуцию в любом форке.

Отправляя изменение, вы подтверждаете право на него и соглашаетесь на распространение по `LicenseRef-Shangin-Attribution-1.0`.
