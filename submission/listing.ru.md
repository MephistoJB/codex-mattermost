# Карточка marketplace

## Название

Mattermost Workflows

## Краткое описание

Сводки, поиск и проверяемые публикации в Mattermost.

## Полное описание

Используйте встроенный локальный MCP, чтобы быстро прочитать активность канала, выделить решения и задачи, найти обсуждения и подготовить новое сообщение или ответ в Mattermost с REST API v4, включая Mattermost 10.11. Администраторский endpoint Agents не нужен. Любая запись фиксируется и показывается для явного подтверждения перед публикацией. Плагин подключается напрямую с компьютера пользователя, не запускает proxy и не отправляет трафик Mattermost издателю.
