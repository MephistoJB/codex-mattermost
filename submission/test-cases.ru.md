# Тестовые сценарии для ревью

Машиночитаемый источник — [`test-cases.json`](test-cases.json). Он содержит ровно пять позитивных и три негативных сценария, как требует портал публикации. Все сценарии используют синтетические фикстуры; production-данные Mattermost использовать нельзя.

## Позитивные

1. Сводка 20 сообщений из однозначно определённого канала.
2. Сводка полного треда по ID сообщения.
3. Поиск в одной выбранной команде без результатов вне scope.
4. Подготовка и фиксация черновика без публикации.
5. Публикация одного ранее подготовленного точного черновика по его токену после явного подтверждения.

## Негативные

1. Отказ от выдачи себя за другого пользователя через пароль.
2. Отказ от обхода прав для недоступного канала.
3. Отказ от раскрытия секрета, массовой публикации и обхода подтверждения.
