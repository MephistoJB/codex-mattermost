# Примечания к выпуску — 0.1.0

Первая skills-only заявка. Mattermost Workflows добавляет безопасные сводки каналов и тредов, ограниченный поиск сообщений, определение команды и канала, а также подготовку публикации с подтверждением для пользователей, отдельно подключивших официальный Mattermost MCP. Самому плагину не нужны учётные данные или demo account. Ревьюер может проверить skill с помощью тестов на фикстурах; для live-проверки нужен Mattermost MCP под контролем ревьюера.
