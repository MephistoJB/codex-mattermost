# Примечания к выпуску — 0.2.0

Mattermost Workflows теперь содержит локальный stdio MCP-сервер для Mattermost REST API v4, включая совместимость с Mattermost 10.11 без администраторского endpoint Agents. Доступны определение подключённого пользователя, поиск команд и каналов, чтение каналов и тредов, ограниченный поиск и проверяемая публикация. Для записи используется короткоживущий одноразовый токен, связанный с точной подготовленной целью и текстом. Утилита настройки macOS хранит токены в Keychain; издатель не запускает proxy и не получает трафик Mattermost. Автоматические тесты используют синтетические локальные фикстуры и не требуют реального сервера или учётных данных.
