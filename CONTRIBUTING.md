# Contributing

[Русская версия](CONTRIBUTING.ru.md)

Contributions are welcome under the repository's attribution-required license.

1. Open an issue describing the workflow or bug.
2. Keep the plugin skills-only and preserve the explicit approval gate before every write.
3. Do not add real Mattermost data or credentials to examples and tests.
4. Update the matching Russian and English documentation.
5. Run `python3 -m unittest discover -s tests -v` and both validators documented in the README.
6. Submit a focused pull request and include the required attribution in any fork.

By contributing, you represent that you have the right to submit the contribution and agree that it is distributed under `LicenseRef-Shangin-Attribution-1.0`.
