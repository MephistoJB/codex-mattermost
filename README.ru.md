# Mattermost Workflows для Codex

[English version](README.md)

Локальный плагин Codex для безопасной работы с Mattermost через встроенный MCP-сервер. Он использует стандартный Mattermost REST API v4 и совместим с Mattermost 10.11, поэтому официальный Agents MCP и права администратора не нужны.

Codex может составлять сводки каналов и тредов, искать сообщения и публиковать проверенный текст. MCP-процесс запускается локально и подключается к Mattermost напрямую с компьютера пользователя. Издатель проекта не получает этот трафик.

> Проект не связан с Mattermost, Inc. или OpenAI, не одобрен и не спонсируется ими.

## MVP

- Определение подключённого пользователя и списка доступных команд.
- Определение команды и канала в пределах существующих прав учётной записи.
- Чтение и сводка канала или треда.
- Поиск сообщений в запрошенной команде или канале.
- Фиксация нового сообщения или ответа, показ точного канала и текста и публикация только после явного подтверждения.
- Хранение локальных учётных данных вне репозитория с поддержкой macOS Keychain.

Создание пользователей, команд и каналов, изменение участников, выдача себя за другого пользователя, вложения, массовые публикации, фоновая индексация и использование cookie браузера не входят в MVP. См. [границы MVP](docs/MVP.ru.md).

## Требования

- Mattermost 10.11 или другая версия с совместимыми endpoint REST API v4.
- Обычная учётная запись Mattermost с доступом к нужным каналам. Права администратора не нужны.
- Codex с поддержкой плагинов и локальных MCP.
- Node.js 18 или новее нужен только для сборки из исходного кода. Готовый сервер включён в плагин.

## Установка

Из marketplace этого репозитория:

```text
codex plugin marketplace add shanginn/codex-mattermost --ref main
codex plugin add mattermost-workflows@personal
```

После установки начните новую задачу, чтобы Codex загрузил плагин и его MCP-сервер.

## Подключение учётной записи Mattermost

В macOS рекомендуемый способ создаёт обычную сессию Mattermost и сохраняет только полученный токен в Keychain. Выполните команду из клона репозитория, локально подставив свой адрес и логин:

```text
node plugins/mattermost-workflows/scripts/configure-macos.mjs \
  --server-url https://chat.example.com \
  --login-id YOUR_LOGIN
```

Пароль вводится интерактивно, не выводится и не сохраняется. Конфигурация записывается в `~/.config/codex-mattermost/config.json`; там есть URL сервера и параметры поиска в Keychain, но нет секрета.

Также можно передать существующий session token или personal access token через стандартный ввод либо использовать переменные окружения `MATTERMOST_URL` и `MATTERMOST_TOKEN`. Никогда не коммитьте эти значения и не вставляйте секреты в чат. Подробнее — в [инструкции по настройке](docs/SETUP.ru.md).

## Примеры запросов

- «Под какой учётной записью я подключён и какие команды Mattermost мне доступны?»
- «Составь сводку решений и задач из указанного мной канала с понедельника».
- «Найди в этой команде сообщения об исчерпании соединений с базой данных».
- «Подготовь уведомление о техобслуживании для указанного мной канала. Не публикуй без моего подтверждения».

## Разработка и тесты

Плагин находится в `plugins/mattermost-workflows`; локальный marketplace — в `.agents/plugins/marketplace.json`.

```text
npm install
npm test
```

Тесты собирают встроенный сервер, проверяют протокол MCP и адаптер Mattermost API на локальных фикстурах, а также manifest плагина, двуязычную документацию, правила безопасности, атрибуцию и сценарии ревью. Подключение к реальному Mattermost не выполняется.
