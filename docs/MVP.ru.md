# Границы MVP

[English version](MVP.md)

## Цель

Дать Codex предсказуемый и проверяемый workflow для типовых задач в Mattermost с REST API v4, включая Mattermost 10.11, без размещённого издателем прокси и администраторских функций Agents.

## Входит в MVP

1. **Локальный stdio MCP-сервер**, включённый в плагин и запускаемый Codex.
2. **Идентификация и поиск целей** через `get_current_user`, `list_teams`, `get_team_info` и `get_channel_info`.
3. **Чтение каналов и тредов** через `read_channel` и `read_post`.
4. **Ограниченный поиск сообщений** через `search_posts` с фильтрами команды и канала.
5. **Проверяемая публикация** в два этапа: `prepare_post` фиксирует точную цель и текст; `create_post` принимает только полученный короткоживущий одноразовый токен после подтверждения пользователем именно этого черновика.
6. **Локальная авторизация** через переменные окружения или пользовательский конфигурационный файл. Утилита для macOS хранит токены в Keychain, а не в репозитории.
7. **Документация на русском и английском**, публичные страницы конфиденциальности, условий и поддержки, тексты marketplace и тестовые сценарии для ревью.

Сервер использует только существующие права подключённой учётной записи Mattermost. Он не расширяет доступ и не предоставляет администраторские операции.

## Не входит в MVP

- MCP-сервис, relay или proxy, размещённый издателем.
- Закоммиченные URL организации, названия workspace, идентификаторы пользователей, секреты, cookie или выгруженное содержимое Mattermost.
- Извлечение сессии или cookie из браузера.
- Создание пользователей, команд или каналов.
- Изменение участников или прав.
- `create_post_as_user`, выдача себя за другого пользователя и dev-инструменты идентификации.
- Вложения и загрузка локальных файлов.
- Массовая или запланированная публикация.
- Фоновая синхронизация, индексация, аналитика или телеметрия.
- Пользовательский интерфейс ChatGPT.

## Критерии готовности

- Валидаторы плагина и skill проходят успешно.
- Автоматические тесты проходят без сети и реальных учётных данных.
- Локальный marketplace Codex устанавливает плагин и запускает встроенный MCP.
- Сервер поддерживает stdio-протокол MCP и сопоставляет инструменты MVP с REST API v4.
- Read-workflow указывают область источников и не выдумывают результаты.
- Изменённый, просроченный или уже использованный токен черновика не может опубликовать сообщение.
- Публичный репозиторий содержит только общие примеры и синтетические фикстуры.
- Пакет для ревью содержит ровно пять позитивных и три негативных сценария.

## Стратегия распространения

Источником распространения служит GitHub-репозиторий. Плагин содержит локальный MCP-процесс, а не публичный HTTP endpoint, поэтому собственный Mattermost-сервис издателя и подтверждение домена не нужны. Пользователь авторизуется в своём Mattermost напрямую на своём компьютере.
