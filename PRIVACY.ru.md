## Данные, обрабатываемые плагином

Встроенный MCP-сервер запускается на компьютере пользователя и подключается напрямую к указанному пользователем адресу Mattermost. Он обрабатывает минимальный набор полей сообщений, каналов, команд и учётной записи, необходимый для запрошенного вызова инструмента. Трафик и содержимое Mattermost не отправляются издателю; аналитики и телеметрии нет.

Сервер не создаёт индекс сообщений и не сохраняет полученное содержимое Mattermost. Только для проверяемой публикации он временно держит в памяти подготовленные черновики; они удаляются через десять минут или при завершении процесса.

Mattermost и среда Codex/ChatGPT пользователя могут обрабатывать и журналировать запросы согласно собственным настройкам администратора, политикам конфиденциальности, правам и срокам хранения.

## Учётные данные и локальная конфигурация

Плагин получает URL сервера и bearer token из защищённых переменных окружения или локальной конфигурации пользователя. В macOS включённая утилита сохраняет токен в Keychain, а в `~/.config/codex-mattermost/config.json` с ограниченными правами записывает только URL и параметры поиска в Keychain.

Реальные URL организации, названия workspace, идентификаторы учётных записей, секреты, cookie и выгруженное содержимое Mattermost не нужны репозиторию и не должны в него попадать. Не добавляйте пароли, токены, OAuth-коды, cookie, закрытые сообщения или конфиденциальные идентификаторы в GitHub Issues и запросы чата.

## Сетевые запросы

Локальный сервер выполняет только запрошенные пользователем HTTPS-вызовы к настроенному Mattermost. Relay издателя не используется. HTTP разрешён только для локальной разработки; нелокальные HTTP URL и URL со встроенными учётными данными отклоняются.

## Данные поддержки

Публичные GitHub Issues и Pull Requests доступны всем. Перед отправкой замените или удалите URL сервера, названия команд и каналов, содержимое сообщений, user ID и чувствительные части ошибок. GitHub обрабатывает данные учётной записи и активности по собственным условиям.
