## Данные, обрабатываемые проектом

Репозиторий содержит инструкции, документацию, metadata и офлайн-утилиту проверки URL. Издатель не запускает сервер для этого плагина. Сам плагин не собирает, не передаёт, не хранит, не продаёт и не анализирует персональные данные, содержимое Mattermost, учётные данные или телеметрию использования.

## Подключённые сервисы

Когда пользователь отдельно подключает Codex к Mattermost MCP, запросы и содержимое Mattermost обрабатываются средой Codex/ChatGPT пользователя и его развёртыванием Mattermost. Действуют их политики конфиденциальности, настройки администратора, права, сроки хранения и журналы. Проект не получает этот трафик.

## Учётные данные

Не передавайте проекту, в GitHub Issues или в запросах чата пароли Mattermost, personal access tokens, OAuth-коды, cookie или другие секреты. Авторизация должна выполняться через MCP-механизм Codex или защищённую локальную конфигурацию.

## Данные поддержки

Публичные GitHub Issues и Pull Requests доступны всем. Не добавляйте туда закрытое содержимое Mattermost или секреты. GitHub обрабатывает данные учётной записи и активности по собственным условиям.

## Изменения и контакты

Существенные изменения фиксируются в истории репозитория. Вопросы о конфиденциальности: Николай Шангин, `shanginn@gmail.com`.
