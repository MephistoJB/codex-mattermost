# Privacy policy

[Русская версия](PRIVACY.ru.md)

Effective date: July 16, 2026

Mattermost Workflows for Codex is a skills-only plugin published by Nikolai Shangin (`shanginn@gmail.com`).

## Data handled by this project

The plugin repository contains instructions, documentation, metadata, and an offline URL-validation helper. The publisher does not operate a server for the plugin. The plugin itself does not collect, transmit, retain, sell, or analyze personal data, Mattermost content, credentials, or usage telemetry.

## Connected services

When a user separately connects Codex to a Mattermost MCP server, requests and Mattermost content are processed by the user's Codex/ChatGPT environment and the user's Mattermost deployment. Their respective privacy terms, administrator settings, permissions, retention policies, and logs apply. This project does not receive that traffic.

## Credentials

Do not provide Mattermost passwords, personal access tokens, OAuth codes, cookies, or other secrets to this project, its issue tracker, or a chat prompt. Authentication should occur through Codex's MCP authentication flow or protected local configuration.

## Support data

Public GitHub issues and pull requests are visible to anyone. Do not include private Mattermost content or credentials. GitHub processes account and activity data under GitHub's own terms.

## Changes and contact

Material changes will be recorded in the repository history. Privacy questions may be sent to Nikolai Shangin at `shanginn@gmail.com`.
