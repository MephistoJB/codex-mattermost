# Support

[Русская версия](SUPPORT.ru.md)

Use [GitHub Issues](https://github.com/shanginn/codex-mattermost/issues) for reproducible bugs and feature requests, or email Nikolai Shangin at `shanginn@gmail.com` for privacy-sensitive support.

Include the plugin version, Codex surface, Mattermost Server/Agents versions, authentication type, expected behavior, and sanitized error text. Never include tokens, passwords, OAuth codes, cookies, private posts, or confidential channel names.

For Mattermost server licensing, OAuth, or administrator configuration, contact your Mattermost administrator or Mattermost support. For Codex account or marketplace issues, use OpenAI support.
