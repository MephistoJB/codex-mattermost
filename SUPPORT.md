# Support

[Русская версия](SUPPORT.ru.md)

Use [GitHub Issues](https://github.com/shanginn/codex-mattermost/issues) for reproducible bugs and feature requests, or email Nikolai Shangin at `shanginn@gmail.com` for privacy-sensitive support.

Include the plugin version, Codex surface, Mattermost Server version, authentication type, expected behavior, and sanitized error text. Replace the server URL, workspace/team/channel names, account and post IDs, and message content. Never include tokens, passwords, OAuth codes, cookies, or private posts.

For Mattermost server policy, SSO, token availability, or administrator configuration, contact your Mattermost administrator or Mattermost support. For Codex account or plugin issues, use OpenAI support.
