# Changelog / История изменений

## 0.2.0 — 2026-07-16

### English

- Added a bundled local stdio MCP server for Mattermost REST API v4, including Mattermost 10.11 compatibility.
- Added identity, team/channel discovery, channel/thread reading, scoped search, and reviewed posting tools.
- Added a two-phase write protocol with expiring, single-use tokens that bind approval to an exact frozen draft.
- Added macOS Keychain configuration and ordinary-session login without storing passwords.
- Added protocol, API-adapter, manifest, privacy, and safety tests using synthetic local fixtures only.
- Updated English and Russian documentation for GitHub distribution without a hosted public MCP service.

### Русский

- Добавлен встроенный локальный stdio MCP-сервер для Mattermost REST API v4, включая совместимость с Mattermost 10.11.
- Добавлены инструменты идентификации, поиска команд и каналов, чтения каналов и тредов, ограниченного поиска и проверяемой публикации.
- Добавлен двухэтапный протокол записи с одноразовыми токенами, которые истекают и связывают подтверждение с точным зафиксированным черновиком.
- Добавлены настройка macOS Keychain и создание обычной сессии без хранения пароля.
- Добавлены тесты протокола, API-адаптера, manifest, конфиденциальности и безопасности только на синтетических локальных фикстурах.
- Русская и английская документация обновлена для распространения через GitHub без публичного MCP-сервиса издателя.

## 0.1.0 — 2026-07-16

### English

- Initial skills-only MVP.
- Added channel/thread summaries, scoped search, target resolution, and reviewed posting workflows.
- Added English and Russian documentation, marketplace metadata, privacy/terms/support pages, and automated tests.

### Русский

- Первый skills-only MVP.
- Добавлены сводки каналов и тредов, ограниченный поиск, определение цели и публикация после подтверждения.
- Добавлены документация на русском и английском, metadata marketplace, страницы конфиденциальности, условий и поддержки, а также автоматические тесты.
